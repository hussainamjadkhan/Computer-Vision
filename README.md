# Computer-Vision# Computer Vision

## About

This repository contains the work for Lab Task 01 of the Computer Vision course.

## images.py

The `images.py` script uses the OpenCV Python library to load an image from the `Images` folder and display it in a window.

## Images

The `Images` folder contains two sample images used for testing the OpenCV image-loading script.
